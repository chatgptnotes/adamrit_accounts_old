FIX PWA Auto-Reload on New Deployment

Mobile users could not see new features after a deploy because they cannot hard-refresh a PWA. The app was stuck running old JS bundles even after a new version was live.

Root Cause

  • Service worker had autoUpdate + skipWaiting + clientsClaim — new SW activated silently
  • But the page kept running old cached JS bundles until user manually refreshed
  • Mobile PWA users have no way to hard-refresh

Fix Applied

  • Added controllerchange listener on navigator.serviceWorker in src/App.tsx
  • When new SW takes control → shows "Updating to latest version…" toast
  • Page auto-reloads after 800ms with new code
  • Double-reload guard prevents firing twice

Result

  • All future deploys will automatically update on every user's phone/tablet
  • No hard refresh required — ever
